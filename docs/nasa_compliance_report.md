### Frame and position checks

- Read five SHA-256-matched official FITS cutouts per target. Compared `DATE-BEG`/`TIMESYS` with the cutout UTC time and archive metadata time, native `DETECTOR` and `OBSID`, spatial WCS `CRVAL` against each epoch-propagated position, local pixel scales, and wavelength. The JSON receipt records exact values for all 25 frames. The SIMBAD ASCII source pages independently returned the exact Barnard and WISE J2000 coordinates, proper motions and bibcodes used in the manifests. The display grid samples at 6.15 arcseconds per pixel. Native sampling and FITS reference centers are separate quantities. All 25 detector and OBSID values matched. Stored frame time matched FITS UTC in all 25. Archive-table times differed by at most 38 ms. The primary labels now follow the FITS clock. Date grouping is still sorted by archive metadata. Native scales ranged from 6.1264″ to 6.1684″ per pixel. Every sampled target lay inside the native cutout. The actual native cutout center was 0.93″ to 101.05″ from the target. The largest offset is R Draconis 2026W39_2A_0591_1, a 46 × 78-pixel partial cutout. The separate display grid is centered on the propagated position.
- Recomputed target wavelengths from the native spectral WCS, interpolated on the native grid for valid centres. Differences from stored display metadata were within 0.0000002 µm in the sample. For invalid centres, the displayed approximate number is the catalog band midpoint. It is not a usable target channel measurement. None of these tests measures a source flux change.
- Independently applied the catalog formula in decimal degrees, converting years from J2000.0 using 365.25 days per year and dividing `pm_ra_cosdec` by `cos(dec)`. Reproduced the stored values to under 0.000001″. Time stamps retain the exposure epoch. This linear model omits annual parallax, radial velocity and perspective effects.

The official scale is 1–5. These are audit estimates using the named [2026 Judging Criteria](https://www.spaceappschallenge.org/resources/judging-awards-guide/#judging-criteria), based on a judge who has two minutes. They are independent of eligibility.
